# Piezas 3D / 3D-printable parts

Piezas que diseñé e imprimí en 3D. GitHub las muestra en 3D: abre cualquier `.stl` y gírala con el ratón.

| Archivo | Qué es |
|---|---|
| `cable-holder.stl` | Soporte para cables |
| `outlet-cover.stl` | Tapa para tomacorriente |
| `charger-cover.stl` | Tapa para cargador (adaptador de corriente de Apple) |

Diseñadas por **John Batista** ([@KleverBatista-max](https://github.com/KleverBatista-max)). Licencia MIT: úsalas, imprímelas y modifícalas libremente.
